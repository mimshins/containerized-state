# Reporting Security Issues

If you believe you have found a security vulnerability in this repo and its
packages, we encourage you to let us know right away. We will investigate all
legitimate reports and do our best to quickly fix the problem.

## How to let us know?

- [Report it privately](https://github.com/mimshins/containerized-state/security/advisories/new)
  through GitHub. Please do not open a public issue: it would disclose the
  vulnerability before there is a fix.
